💄 Maquillaje

Elige el estilo de maquillaje que quieras aprender ✨

🌷 Maquillaje sencillo

Un look natural y fácil para todos los días.

  1. Preparar la piel
  2. Corrector opcional
  3. Rubor
  4. Máscara de pestañas
  5. Bálsamo labial

🎀 Maquillaje natural

Para conseguir un look fresco sin complicarse demasiado.

  1. Hidratante
  2. Protector solar
  3. Corrector opcional
  4. Rubor
  5. Brillo labial

✨ Maquillaje para salir

Un look un poco más elaborado para una ocasión especial.

  1. Preparar la piel
  2. Base o corrector
  3. Rubor
  4. Sombras
  5. Pestañas
  6. Labios

🌸 Maquillaje de ojos

Ideas para practicar diferentes estilos de sombras.

  1. Preparar los párpados
  2. Aplicar sombra clara
  3. Agregar una sombra más intensa
  4. Delineado opcional
  5. Máscara de pestañas

🧴 Skincare

Escoge la rutina que quieras conocer 🌸

🌞 Skincare de mañana

Una rutina sencilla para comenzar el día.

  1. Limpiar suavemente
  2. Hidratar
  3. Protector solar

🌙 Skincare de noche

Una rutina sencilla para antes de dormir.

  1. Retirar maquillaje si lo usaste
  2. Limpiar
  3. Hidratar

💗 Skincare básico

Una opción sencilla para comenzar a conocer el cuidado de la piel.

  1. Limpieza
  2. Hidratación
  3. Protector solar durante el día

✨ Preparar la piel

Pasos sencillos antes de aplicar maquillaje.

  1. Limpiar
  2. Hidratar
  3. Esperar unos minutos
  4. Continuar con maquillaje si quieres

🎀 Cabello

Encuentra diferentes ideas para tu cabello 💕

🎀 Peinado sencillo

Una opción rápida para el día a día.

  1. Desenredar
  2. Separar el cabello
  3. Peinar
  4. Agregar un accesorio

🌸 Trenza fácil

Una trenza sencilla para practicar.

  1. Desenredar
  2. Dividir el cabello
  3. Comenzar la trenza
  4. Asegurar con una liga

✨ Coleta bonita

Una opción rápida que puedes decorar con accesorios.

  1. Peinar
  2. Recoger el cabello
  3. Asegurar la coleta
  4. Agregar un accesorio

🌙 Cabello para salir

Ideas para cuando quieras un peinado un poco diferente.

  1. Desenredar
  2. Separar el cabello
  3. Elegir un peinado
  4. Agregar accesorios
